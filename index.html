Daypad 사용법

두 번 클릭
그 자리에 클립보드 내용 붙여넣기 (글·그림)
한 번 클릭
커서가 생겨요. 쓰거나 Ctrl+V 하고 다른 곳을 누르면 저장
글
잡고 끌면 이동 · 클릭하면 위에 복사 · 수정 · 지움이 뜨고, 오른쪽 아래 점을 끌면 폭 조절
사진
잡고 끌면 이동 · 두 번 클릭하면 원래 크기 · 모서리 점을 끌면 크기 조절
Delete
고른 것 삭제
빈 곳 끌기
종이 이동 · Ctrl+휠 또는 Ctrl + / − 로 확대/축소, Ctrl 0 원래대로
모아보기 · Home
흩어진 것을 차곡차곡 정렬 · Shift+Home은 축소해서 전체 보기
날짜 클릭
지난 판 보기 · 이 판 비우기 · 종이색 · 글자 크기

판은 날짜별로 나뉘고 3일이 지나면 저절로 사라져요. 내용은 이 기기 브라우저 안에만 저장됩니다.
